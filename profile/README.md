# Grimoire Codex

**Self-hosted TTRPG library management — and the community building around it.**

[Website](https://grimoirecodex.org) · [Documentation](https://docs.grimoirecodex.org) · [Live Demo](https://demo.grimoirecodex.org) · [Discord](https://discord.gg/9Sd4CGZC63)

</div>

---

Grimoire is a Docker-based web app for organizing and reading your tabletop RPG
collection — PDFs, maps, tokens, audio, and campaigns — from any device, with
full-text search across every page and a clean, responsive UI.

## Repositories

| Repo                                                                         | What it is                                                                                        |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| [**grimoire**](https://github.com/hunter-read/grimoire)                      | The main application — FastAPI backend + React frontend, shipped as a Self Hostable Docker image. |
| [**docs**](https://github.com/grimoire-codex/docs)                           | The documentation site published at [docs.grimoirecodex.org](https://docs.grimoirecodex.org).     |
| [**community-add-ons**](https://github.com/grimoire-codex/community-add-ons) | Community-contributed extras — campaign wiki templates, scrapers, plugins, and more.              |

## Get started

The fastest way in is the [Quick Start](https://docs.grimoirecodex.org) in the
docs, or try the [live demo](https://demo.grimoirecodex.org) first to see what
Grimoire does.

## Get involved

- 💬 **Chat & help** — join the [Discord server](https://discord.gg/9Sd4CGZC63).
- 🐛 **Report a bug or request a feature** — open an issue on the relevant repo.
- 🧩 **Share an add-on** — templates, scrapers, and plugins are welcome in
  [community-add-ons](https://github.com/grimoire-codex/community-add-ons).
- 🌍 **Translate** — new and improved translations are always welcome; see the
  contributing guide.
