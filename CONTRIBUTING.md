# Contributing to Grimoire Codex

Thanks for your interest in contributing! Contributions of all kinds are
welcome — bug reports, feature ideas, documentation improvements, code,
translations, and community add-ons.

This is the organization-wide default guide. Some repositories have their own
`CONTRIBUTING.md` with project-specific setup and conventions — when they do,
that file takes precedence for work in that repo.

## Which repo?

- **[grimoire](https://github.com/hunter-read/grimoire)** — the application
  itself (bugs, features, code, translations).
- **[docs](https://github.com/grimoire-codex/docs)** — the documentation site.
- **[community-add-ons](https://github.com/grimoire-codex/community-add-ons)** —
  campaign wiki templates, scrapers, plugins, and other community extras.

## Reporting a bug or requesting a feature

Open an issue in the relevant repository and pick the template that fits:

- **Bug Report** — something is broken or behaving unexpectedly
- **Feature Request** — an idea or improvement you'd like to see
- **Question / Help** — not sure how something works, or need help getting set up

> Before opening a new issue, a quick search of the existing issues can save
> time — someone may have already reported the same thing.

## Contributing code

1. **Open an issue first** for anything beyond a small fix — it's worth aligning
   on the approach before you invest time writing code.
2. Fork the repo and create a feature branch off `main`.
3. Make your changes, and run the project's test suite before opening a PR. See
   the repo's own README / `CONTRIBUTING.md` for how to build and test it.
4. Open a pull request against `main`. The PR template will prompt you for a
   summary and testing notes.

## Sharing a community add-on

Templates, scrapers, and plugins live in
[community-add-ons](https://github.com/grimoire-codex/community-add-ons). See
that repo's README for how contributions are organized and submitted.

## Translations

Grimoire supports multiple languages, and new or improved translations are
always welcome. Review the existing locale files to follow the current format,
and open a pull request — no issue is required for translation-only PRs. If you'd
rather not open a PR, reach out on Discord and we can coordinate there.

## Community

Join the [Discord server](https://discord.gg/9Sd4CGZC63) to chat, share
feedback, or get help.

## Security vulnerabilities

Please do **not** open a public issue for security vulnerabilities. Report them
privately per the `SECURITY.md` in the affected repository.
